# 모아 가계부

개인지출·고정지출 예산과 카드별 실적을 관리하는 단일 HTML 가계부 초안입니다.

## 실행

`index.html` 파일을 웹 브라우저로 열면 됩니다.

## 휴대폰에서 열기

GitHub Pages가 활성화된 뒤에는 다음 주소에서 열 수 있습니다.

`https://910827.github.io/ina-household-ledger/`

배포는 `main` 브랜치에 변경 사항을 푸시하면 자동으로 갱신됩니다.

## 현재 상태

- 거래 추가·수정·삭제
- 개인지출과 고정지출 예산 설정
- 현대경차·현대네이버 카드 실적 관리
- 브라우저 로컬 저장소 기반 데이터 보관

거래 데이터는 기본적으로 브라우저에 저장됩니다. 로그인하면 Supabase를 통해 같은 계정의 다른 기기와 거래·예산을 동기화할 수 있습니다.

## 코드 구성

- `index.html`: 화면의 구조와 외부 파일 연결
- `styles.css`: 데스크톱·모바일 화면 스타일
- `app.js`: 거래 입력, 월별 집계, 예산, 카드 실적, 상세 보기와 브라우저 로컬 저장소
- `supabase-sync.js`: 로그인, 클라우드 병합, 거래·예산 동기화
- `supabase-migration.sql`: 삭제 거래의 기기 간 동기화를 위한 데이터베이스 변경

화면 기능은 `app.js`에서만 수정하고, 동기화와 관련된 변경은 `supabase-sync.js`에서 처리합니다. 동기화 기능을 사용하기 전에 `supabase-migration.sql`을 Supabase SQL Editor에서 한 번 적용해야 합니다.
