# 모아 가계부

개인지출·고정지출 예산과 카드별 실적을 관리하는 단일 HTML 가계부 초안입니다.

## 실행

`index.html` 파일을 웹 브라우저로 열면 됩니다.

## 휴대폰에서 열기

GitHub Pages가 활성화된 뒤에는 다음 주소에서 열 수 있습니다.

`https://910827.github.io/ina-household-ledger/`

배포는 `main` 브랜치에 변경 사항을 푸시하면 자동으로 갱신됩니다.

## 현재 상태

- 거래 추가·수정·삭제
- 개인지출과 고정지출 예산 설정
- 현대경차·현대네이버 카드 실적 관리
- 브라우저 로컬 저장소 기반 데이터 보관

거래 데이터는 현재 브라우저에 저장됩니다. 다른 기기와 데이터를 공유하려면 향후 로그인 및 클라우드 데이터베이스 연동이 필요합니다.
